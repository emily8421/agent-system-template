## 权限级别

- **低**：只读 / 无副作用，自动允许。
- **中**：有副作用但可逆（如写临时文件），记录即可。
- **高**：不可逆或高影响（发请求 / 花钱 / 删数据 / 对外写入），必须人工确认或沙箱。

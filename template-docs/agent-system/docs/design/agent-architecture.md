## 角色与边界

| 角色 | 职责 | 边界 / 禁止 |
|---|---|---|
| Planner | 拆解任务、规划步骤 | 不直接执行工具 |
| Executor | 执行单步 / 调用工具 | 不越权、不超范围 |
| Tool router | 选择与路由工具 | 不绕过权限检查 |
| Memory | 读写上下文 / 记忆 | 不存敏感明文 |
| Evaluator | 评估结果 / 决定终止或重试 | 不替人做最终决策（高风险项） |
| Supervisor（可选） | 监督 / 介入 / 回滚 | — |
